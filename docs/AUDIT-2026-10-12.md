==================================================
1. Keputusan arsitektur: Pilih (a) lanjut local-first sepenuhnya, atau (b) kembalikan ke Supabase-native. Keduanya tidak boleh campur-campur.
2. Jika local-first: Hapus `process.env.GEMINI_API_KEY` dari ai.dispatch atau tambahkan validasi di server.

4. Implementasi realtime cross-instance via WebSocket/SSE benar-benar (bukan stub in-memory).
5. Tambah fitur WebPush (VAPID subscription + server endpoint).
6. Buat API sync/outbox yang menyimpan ke localDB dan coba sync ke server jika ada.
7. Review dan hapus referensi Supabase lama di README/AGENTS.md, atau tambahkan catatan "sebelum pivot ke local".
